# AstrBot 全量余额查询插件

一个用于 AstrBot 的余额查询插件。发送 `/余额`，即可查询配置好的 New API 账户余额和 DeepSeek 官方 API 余额。支持固定模板回复，也可开启 LLM 自然语言转述。

作者：**洛奈Hayes**  
作者 QQ：**3186125403**

## 功能

- 一条指令同时查询 New API 与 DeepSeek 余额
- 默认使用固定回复模板，不调用 LLM
- 支持在插件设置中自定义回复内容和排版
- 可选启用 LLM 自然语言回复，模型不可用时回退到模板，日志显示调用和回退原因
- New API 与 DeepSeek 查询彼此独立，一方失败时仍显示另一方结果
- 默认仅允许 AstrBot 管理员查询，可在设置中调整

## 指令

| 指令 | 作用 | 说明 |
| --- | --- | --- |
| `/余额` | 查询余额 | 查询插件配置的 New API 账户和 DeepSeek 官方账户余额 |

指令需要 AstrBot 的唤醒前缀（默认为 `/`），或 @机器人 后发送。若修改过唤醒前缀，请使用新的前缀。

## 安装

在 AstrBot WebUI 的「插件」页面上传插件 ZIP。安装后启用插件，并在插件页面打开「全量余额查询」的设置。

也可以手动安装：将插件文件放入 AstrBot 的 `data/plugins/astrbot_plugin_all_balance/` 目录，然后重启 AstrBot 或在 WebUI 中重载插件。

适配 AstrBot 4.x，要求 AstrBot >=4.5.7。

## 插件设置

在「插件 → 全量余额查询 → 配置」中填写：

| 设置项 | 说明 |
| --- | --- |
| New API 站点地址 | 默认 `https://new.jzeri.cn`。填写 HTTPS 站点根地址，不要添加 `/v1`。 |
| New API 系统访问令牌 | 用于账户管理接口的访问令牌；不是模型调用用的 `sk-` API Key。只填写令牌本身，不要加 `Bearer`。 |
| New API 用户 ID | 通常留空。若旧版站点提示需要 `New-Api-User`，填写访问令牌所属账户的数字 ID。 |
| DeepSeek 官方 API Key | 在 DeepSeek 官方平台创建的 API Key，不是 New API 的转发密钥。 |
| 自定义回复模板 | 设置余额回复文字，必须同时包含下方说明的两个占位符。 |
| 启用 LLM 自然语言回复 | 默认关闭。开启后按 AstrBot 当前会话生效的人格回复，可能产生模型调用费用。 |
| 自然语言回复模型 | 可选择已配置的模型；留空则使用当前会话模型。此设置仅改变模型，不改变人格。 |
| 仅允许 AstrBot 管理员查询 | 默认开启。关闭后其他用户也能查询这组账户余额。群聊中的回复对群成员可见。 |
| 请求超时时间 | 余额 HTTP 请求超时，默认 15 秒，可设置为 1–60 秒。 |
| LLM 回复超时时间 | 默认 60 秒，可设置为 5–300 秒；推理模型可适当提高。 |

填写令牌后保存设置，并重载插件。

### 获取 New API 系统访问令牌

登录 New API 网站，进入个人安全页面的「访问令牌」区域。本站可直接打开：`https://new.jzeri.cn/security`。

点击「生成」并完成安全验证后，在弹出的窗口中立即复制令牌。令牌关闭弹窗后无法再次查看；重新生成会使旧令牌失效，记得同步更新其他使用旧令牌的程序。请勿将令牌发送给他人或提交到公开仓库。

### 获取 DeepSeek API Key

在 DeepSeek 官方平台创建 API Key，并将其填入插件设置。请勿把密钥发到群聊或公开仓库。

## 自定义回复模板

在插件设置的「自定义回复模板」中填写想要的回复文本，可直接换行。

必须同时包含以下两个占位符：

- `{newapi_balance}`：替换为 New API 余额和币种；查询失败时显示失败原因。
- `{deepseek_balance}`：替换为 DeepSeek 余额和币种；查询失败时显示失败原因。

默认模板：

```text
当前New API余额为：{newapi_balance}
deepseek余额为：{deepseek_balance}
```

自定义示例：

```text
💰 账户余额
New API：{newapi_balance}
DeepSeek：{deepseek_balance}
```

占位符可以重复使用。留空、使用未知字段、缺少任一占位符、模板格式错误或超过 4000 个字符时，插件将回退到默认模板。如需显示普通花括号，请输入 `{{` 和 `}}`。

关闭 LLM 时按模板原样回复。开启 LLM 后模型可能改写措辞；如需严格保持自定义格式，请关闭 LLM。余额查询失败时，模板会显示失败原因，不会把失败误报为零余额。

## 管理员配置（AstrBot 4.x）

默认只有 AstrBot 管理员可以使用 `/余额`。如果提示没有权限，请在 AstrBot 当前使用的配置文件中检查管理员 ID：

1. 发送 `/sid`，记下输出中的 UID。
2. 打开 WebUI 的「配置文件 → 访问控制 → 管理员 → 管理员 ID」，添加该 UID 并保存。
3. 确认修改的是机器人当前实际使用的配置文件。

也可以在插件设置中关闭「仅允许 AstrBot 管理员查询」，允许其他人使用。注意：群聊回复对群成员可见。

## 余额说明

插件查询的是插件凭据对应账户的 New API 钱包余额，以及 DeepSeek 官方账户余额；不是每位聊天用户各自的余额，也不是 New API 模型调用令牌的独立额度。New API 的显示币种和换算依据站点设置。

## 常见问题

**Q：New API 查询提示鉴权失败？**  
A：确认填写的是「系统访问令牌 / 访问令牌」，而不是模型调用用的 `sk-` API Key；不要在令牌前加 `Bearer`。令牌重新生成后，旧令牌会立即失效。

**Q：DeepSeek 查询失败？**  
A：确认填写的是 DeepSeek 官方 API Key，检查密钥状态和 AstrBot 所在主机的网络连接。

**Q：模板没有按预期显示？**  
A：确认 `{newapi_balance}` 和 `{deepseek_balance}` 两个占位符都存在，且没有拼错。若开启了 LLM，模型可能改写格式；关闭 LLM 即可按模板原样输出。

**Q：群里发送 `/余额` 没有触发？**  
A：确认使用了 AstrBot 当前的唤醒前缀，且群聊中满足机器人的唤醒规则。

## 开源说明

你可以自由修改和分发本插件。建议保留作者信息，方便后续维护和交流。

**Q：开启 LLM 后仍然显示模板？**  
A：保存设置并重载插件，明确选择一个可用的聊天模型后再次发送 `/余额`。查看 AstrBot 日志中的“全量余额查询”：开始调用、生成成功、模型未配置、超时或校验不通过都会记录。不显示凭据和余额正文。

## LLM 人格回复

开启 LLM 后，插件读取 AstrBot 当前会话选择的人格，并使用该人格的语气回复；无需在插件中重复配置人格。支持当前版本核心的会话规则人格及配置文件默认人格解析。未选择人格时不会强行指定“余额播报助手”。

为避免余额记录影响后续聊天，本插件仅借用人格提示词，不读取或写入聊天历史，也不执行人格工具、知识库或完整 Agent 流程。WebChat 特殊内置默认提示词不由插件复制。旧版缺少核心人格解析器时仅兼容对话所选人格和默认人格。
